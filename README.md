# Company Sales Report Dashboard

An interactive Power BI dashboard that analyzes company sales performance from a retail orders dataset.

## What it shows
- Sales share by customer segment (pie chart)
- Sales trend over time by order date (line chart)
- Total sales, profit, quantity, and discount (headline metrics)
- Sub-category ranking by sales (funnel chart)
- Sales by state (map) and by region (donut chart)

## Tech
- Power BI Desktop (.pbix)
- Single `Orders` table with fields: Sales, Profit, Quantity, Discount, Order Date, Segment, Sub-Category, Region, State

## How to open
Download `company_sales_report_dashboard.pbix` and open it in Power BI Desktop.
